## **SwingSet Engine**

If you are just learning java and you (or whatever course you might be using) has started to introduce the framework **awt** or **swing** this might be the perfect engine for you to create simple 2D games.

Many tutorial on awt or swing are focused on the application aspect of the framework. Therefore it might be hard to get something going – thus delaying the actual game making part.

My goal was never to hide away everything behind some fancy UI or methods – you are actually using awt/swings own method and Graphics class when making your game. I only try to make getting started go by quicker and collect everything in one context.

### Some features:

- Completely custom cursor support
- Reimplemented UI classes that share the same graphical context
- Menu managing system
